# Robot Dog Visualization

A simple HTML and JavaScript robot dog visualization with animation.

## Features

- Animated robot dog with walking animation
- Tail wagging effect
- Interactive controls (start, stop, reset)
- Adjustable animation speed
- Automatic direction change at canvas edges

## Usage

Simply open `index.html` in a web browser to view the robot dog visualization.

### Controls

- **Start Animation**: Begin the robot dog walking animation
- **Stop Animation**: Pause the animation
- **Reset**: Reset the dog to the center position
- **Speed Slider**: Adjust the animation speed (1-10)

## Files

- `index.html` - Main HTML file
- `styles.css` - Styling for the visualization
- `robot-dog.js` - JavaScript code for the robot dog animation

## How it Works

The robot dog is drawn using HTML5 Canvas API with JavaScript. The animation includes:
- Leg movement synchronized in a walking pattern
- Tail wagging motion
- Horizontal movement across the canvas
- Automatic direction reversal at boundaries
